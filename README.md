# What Dat Temp Dew — marketing site

Static site for the What Dat Temp Dew iOS app, published with GitHub Pages at
https://timhibbard.github.io/what-dat-temp-dew-marketing/

- `/` landing page
- `/privacy/` privacy policy (App Store privacy policy URL)
- `/support/` support page (App Store support URL)

`app-ads.txt` lives at the domain root in `timhibbard/timhibbard.github.io` and already lists the AdMob publisher ID.

Plain HTML/CSS, no build step. Push to `main` to publish.
